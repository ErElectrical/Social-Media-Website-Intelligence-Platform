# SocialWebIntelligence – Project Progress Update

**Last Updated:** 12 November 2026

## 1. Project Overview

SocialWebIntelligence is a web-based intelligence platform developed using ASP.NET Core MVC, .NET Worker Services, C#, MariaDB and Entity Framework Core.

The primary objective is to collect publicly accessible information from company websites and social media platforms, organize the collected information, maintain historical records and identify meaningful changes over time.

The project is being developed incrementally, with website intelligence as the current primary focus.

## 2. Technology Stack

- **Backend:** C#, ASP.NET Core MVC, .NET 9
- **Background Processing:** .NET Worker Service
- **Database:** MariaDB
- **ORM:** Entity Framework Core
- **HTML Parsing:** HtmlAgilityPack
- **Frontend:** HTML, CSS, Bootstrap, JavaScript
- **Testing:** xUnit, EF Core InMemory

## 3. Implemented Features

### 3.1 Website Page Discovery

Implemented `WebsitePageDiscoveryService` to discover relevant pages from company websites.

Supported page types:

- Contact
- About
- Products
- Services
- News
- Careers

Current capabilities:

- Identifies relevant pages using hyperlinks, link text and URL paths.
- Resolves relative URLs.
- Restricts discovery to the original website host.
- Removes URL fragments.
- Prevents duplicate URLs.
- Supports recursive page discovery.
- Provides configurable maximum discovery depth and page count.
- Uses HTTP requests and HtmlAgilityPack for HTML retrieval and parsing.

Default discovery configuration:
- Maximum depth: 2
- Maximum discovered pages: 50

### 3.2 Discovered Pages Dashboard

Implemented a Discovered Pages interface in the Sources section.

The interface displays:

- Company name
- Website URL
- Total discovered pages
- Page type
- Discovered page URL
- Link to open the original webpage
- Refresh Discovery functionality

The discovery functionality has also been tested against a locally hosted sample website.

### 3.3 Website Contact Intelligence

Implemented the Contact Page collection workflow.

The system:
- Discovers Contact pages.
- Downloads Contact page HTML.
- Extracts publicly available contact information.
- Extracts page title and metadata.
- Generates a SHA-256 content hash.
- Returns structured collection results.

### 3.4 About Page Intelligence

Implemented a dedicated About Page extraction and persistence workflow.

The system extracts:
- Page title
- Meta description
- Main heading
- Section headings
- Description paragraphs

Additional capabilities:
- Serializes extracted information into JSON.
- Generates a content hash from structured information.
- Compares new information with previous successful collections.
- Identifies meaningful changes.
- Saves collection snapshots.
- Maintains historical change records.
- Provides About History and change-detail interfaces.

### 3.5 General Page Intelligence – Products and Services

Started a reusable extraction and collection pipeline for Products and Services pages.

**GeneralPageInformationExtractor**

Extracts:
- Page title
- Meta description
- Main heading
- H2 and H3 headings
- Description paragraphs
- List items

The extractor also:
- Removes navigation, header, footer, script, style, noscript and SVG elements.
- Decodes HTML entities.
- Normalizes whitespace.
- Removes duplicate extracted text.

**GeneralPageCollectionService**

Implemented the collection service responsible for:
- Validating HTTP and HTTPS URLs.
- Downloading webpage HTML.
- Calling the general information extractor.
- Generating a SHA-256 hash from serialized structured information.
- Returning a `GeneralPageCollectionResult`.

**Products and Services Details Views**

Created separate MVC views:
- `ProductDetails.cshtml`
- `ServiceDetails.cshtml`

Connected these views to the Discovered Pages interface through a View Details action.

Currently, these views collect information live when opened. General Products and Services database persistence has not yet been implemented.

## 4. Database Design and Existing Persistence

The project already uses the following generic website collection structure:

**WebsiteCollection**
- Stores the monitored source ID.
- Stores page URL and page type.
- Stores extracted information as JSON.
- Stores content hash and HTTP status.
- Tracks collection success and collection time.
- Stores collection error information.

**WebsiteCollectionChanges**
- Maintains historical change information associated with website collections.

The existing About Page persistence workflow uses these structures. The new Products and Services collection pipeline has not yet been connected to database persistence.

No additional database entity or migration has been introduced for General Page Intelligence so far.

## 8. Conclusion

SocialWebIntelligence has progressed from a basic website collection application into a multi-page website intelligence platform.

The current implementation supports website page discovery, recursive crawling, Contact information extraction, About page intelligence, historical change tracking and initial Products and Services information extraction.

The architecture is being developed around reusable extraction and collection services, with structured information stored as JSON and content hashes used to identify changes.

The next major milestone is to integrate the new General Page Collection pipeline with database persistence and historical change detection. This will allow the platform to move beyond simply discovering and displaying company webpages toward continuously monitoring and tracking changes in company information.
