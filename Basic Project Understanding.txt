# SocialWebIntelligence — Project Understanding

## 1. Project Overview

**Project Name:** SocialWebIntelligence  
**Project Type:** Business Intelligence and Web Data Automation Platform  
**Primary Technology:** C#, ASP.NET Core MVC, .NET 9, Entity Framework Core, MariaDB  
**Development Environment:** Visual Studio 2022  
**Purpose:** To collect, process, store, monitor and analyze publicly accessible business information from company websites and authorized social media sources.

SocialWebIntelligence is designed to help businesses gather useful information about their own websites, competitors and other publicly accessible business sources.

The system aims to automate information collection and provide structured data, historical records, change detection, dashboards and reports.

The project is being developed as a professional software portfolio project and as a foundation for delivering custom business intelligence and data automation solutions to freelance clients.

---

## 2. Main Objectives

The platform is intended to provide the following capabilities:

1. Register and manage companies and their monitored sources.
2. Discover relevant pages on company websites.
3. Extract publicly available business information.
4. Store extracted information in MariaDB.
5. Maintain historical collection records.
6. Detect changes in previously collected information.
7. Monitor multiple website sections.
8. Automate recurring data collection.
9. Display collected information through an administrative dashboard.
10. Export collected information into CSV, Excel and JSON formats.
11. Support authorized social media data integrations.

## 6. Existing Website Collection Workflow

The current implementation focuses on collecting Contact Us information.

The workflow is:

1. A user registers a company and its website.
2. The application retrieves the website homepage.
3. WebsitePageDiscoveryService searches for a Contact Us page.
4. The service resolves the discovered page URL.
5. WebsiteContactCollectionService downloads the Contact Us page.
6. ContactInformationExtractor parses the HTML.
7. Contact information is structured into a ContactInformation DTO.
8. WebsiteContactCollectionResult contains the extracted information and collection metadata.
9. WebsiteCollectionPersistenceService serializes the information into JSON.
10. A WebsiteCollection record is inserted into MariaDB.
11. The source's LastCollectedAt property is updated.

### Information currently extracted

- Email addresses
- Phone numbers
- Physical addresses
- Social media links

The extraction logic uses HTML structure and pattern matching. It does not require an AI API.

## 9. Development Roadmap

### Phase 1 — Website Contact Intelligence

**Status: Completed**

Build a working workflow for discovering Contact Us pages, extracting contact information and saving structured results.

### Phase 2 — Website Change Detection

**Status: Next**

Objectives:

- Normalize extracted contact information.
- Generate consistent SHA-256 fingerprints.
- Compare newly collected information with the latest successful snapshot.
- Detect new, changed and unchanged information.
- Avoid storing unnecessary duplicate snapshots.
- Preserve historical versions.
- Identify exactly which fields changed.

Example:

Previous email: `sales@company.com`

New email: `contact@company.com`

Expected result: The system detects an email change and preserves both snapshots.

Important design decision:

The fingerprint should represent normalized extracted information, not the entire raw HTML document. This avoids false change notifications caused by unrelated dynamic website content.

### Phase 3 — Multi-Page Intelligence

- About Us

## 10. Important Engineering Principles

The following principles should guide future development.

1. Prefer simple and maintainable architecture.
2. Avoid unnecessary abstractions and additional projects.
3. Reuse existing services where appropriate.
4. Keep business logic separate from controllers.
5. Use asynchronous methods for I/O operations.
6. Handle HTTP failures and invalid responses properly.
7. Prevent duplicate historical records.
8. Maintain collection history.
9. Write automated tests for important business rules.
10. Avoid storing passwords, API keys or secrets in source control.
11. Respect website terms, robots policies, access controls and rate limits.
12. Do not bypass HTTP 403 responses or platform restrictions.
13. Do not introduce paid APIs or infrastructure.
14. Avoid unnecessary AI integration.

using System.Text.RegularExpressions;
using HtmlAgilityPack;
using SocialWebIntelligence.Core.DTOs;

namespace SocialWebIntelligence.Infrastructure.Collectors.Websites;

/// <summary>
/// Extracts publicly displayed contact information from website HTML.
/// This class does not download websites or save anything to the database.
/// </summary>
public class ContactInformationExtractor
{
    // Matches common email address formats.
    private static readonly Regex EmailRegex = new(
        @"[A-Z0-9._%+\-]+@[A-Z0-9.\-]+\.[A-Z]{2,}",
        RegexOptions.IgnoreCase | RegexOptions.Compiled);

    // Finds potential phone numbers. Candidates are filtered by digit count.
    private static readonly Regex PhoneRegex = new(
        @"(?<!\w)\+?\d[\d\s().\-]{5,}\d(?!\w)",
        RegexOptions.Compiled);

    /// <summary>
    /// Extracts contact information from an HTML document.
    /// </summary>
    public ContactInformation Extract(string html)
    {
        if (string.IsNullOrWhiteSpace(html))
            throw new ArgumentException("HTML content cannot be empty.", nameof(html));

        var result = new ContactInformation();

        var document = new HtmlDocument();
        document.LoadHtml(html);

        ExtractEmails(document, result);
        ExtractPhoneNumbers(document, result);
        ExtractAddresses(document, result);
        ExtractSocialLinks(document, result);

        return result;
    }

    /// <summary>
    /// Finds email addresses in visible page text and mailto links.
    /// </summary>
    private static void ExtractEmails(
        HtmlDocument document,
        ContactInformation result)
    {
        var pageText = HtmlEntity.DeEntitize(
            document.DocumentNode.InnerText ?? string.Empty);

        AddUnique(
            result.Emails,
            EmailRegex.Matches(pageText)
                .Select(match => match.Value.Trim()));

        var emailLinks = document.DocumentNode.SelectNodes(
            "//a[starts-with(translate(@href,'MAILTO','mailto'),'mailto:')]");

        if (emailLinks == null)
            return;

        foreach (var link in emailLinks)
        {
            var href = link.GetAttributeValue("href", "");
            var email = href["mailto:".Length..].Split('?')[0].Trim();

            if (EmailRegex.IsMatch(email))
                AddUnique(result.Emails, new[] { email });
        }
    }

    /// <summary>
    /// Finds potential phone numbers in page text and telephone links.
    /// </summary>
    private static void ExtractPhoneNumbers(
        HtmlDocument document,
        ContactInformation result)
    {
        var pageText = HtmlEntity.DeEntitize(
            document.DocumentNode.InnerText ?? string.Empty);

        var candidates = PhoneRegex.Matches(pageText)
            .Select(match => match.Value);

        AddValidPhoneNumbers(result, candidates);

        var phoneLinks = document.DocumentNode.SelectNodes(
            "//a[starts-with(translate(@href,'TEL','tel'),'tel:')]");

        if (phoneLinks == null)
            return;

        foreach (var link in phoneLinks)
        {
            var href = link.GetAttributeValue("href", "");
            var phone = href["tel:".Length..].Split('?')[0].Trim();

            AddValidPhoneNumbers(result, new[] { phone });
        }
    }

    /// <summary>
    /// Finds addresses in semantic HTML and common address-related attributes.
    /// </summary>

    private static readonly Regex AddressIndicatorRegex = new(
        @"\b(road|rd\.?|street|st\.?|highway|distt\.?|district|sector|"
        + @"village|city|haryana|india|pin|postal code)\b|\b\d{6}\b",
        RegexOptions.IgnoreCase | RegexOptions.Compiled);

    private static void ExtractAddresses(
        HtmlDocument document,
        ContactInformation result)
    {
        var addressNodes = document.DocumentNode.SelectNodes(
            "//address | " +
            "//*[@itemprop='address'] | " +
            "//*[contains(translate(@class,'ADDRESS','address'),'address')] | " +
            "//*[contains(translate(@id,'ADDRESS','address'),'address')] | " +
            "//p");

        if (addressNodes == null)
            return;

        foreach (var node in addressNodes)
        {
            var address = CleanText(node.InnerText);

            if (string.IsNullOrWhiteSpace(address))
                continue;

            // Paragraphs are considered addresses only when
            // they contain recognizable address indicators.
            bool isSemanticAddress =
                node.Name.Equals("address", StringComparison.OrdinalIgnoreCase) ||
                node.GetAttributeValue("itemprop", "")
                    .Equals("address", StringComparison.OrdinalIgnoreCase) ||
                node.GetAttributeValue("class", "")
                    .Contains("address", StringComparison.OrdinalIgnoreCase) ||
                node.GetAttributeValue("id", "")
                    .Contains("address", StringComparison.OrdinalIgnoreCase);

            bool hasAddressIndicators =
                AddressIndicatorRegex.IsMatch(address);

            if (isSemanticAddress || hasAddressIndicators)
            {
                AddUnique(result.Addresses, new[] { address });
            }
        }
    }


    /// <summary>
    /// Finds links pointing to recognised social media platforms.
    /// </summary>
    private static void ExtractSocialLinks(
        HtmlDocument document,
        ContactInformation result)
    {
        var links = document.DocumentNode.SelectNodes("//a[@href]");

        if (links == null)
            return;

        foreach (var link in links)
        {
            var href = link.GetAttributeValue("href", "").Trim();

            if (!Uri.TryCreate(href, UriKind.Absolute, out var uri))
                continue;

            if (uri.Scheme != Uri.UriSchemeHttp &&
                uri.Scheme != Uri.UriSchemeHttps)
                continue;

            var host = uri.Host.ToLowerInvariant();

            string? platform = host switch
            {
                "linkedin.com" or "www.linkedin.com" => "LinkedIn",
                "facebook.com" or "www.facebook.com" => "Facebook",
                "instagram.com" or "www.instagram.com" => "Instagram",
                "x.com" or "www.x.com" or
                "twitter.com" or "www.twitter.com" => "X",
                "youtube.com" or "www.youtube.com" => "YouTube",
                _ => null
            };

            if (platform == null)
                continue;

            if (!result.SocialLinks.ContainsKey(platform))
                result.SocialLinks[platform] = new List<string>();

            AddUnique(result.SocialLinks[platform], new[] { uri.AbsoluteUri });
        }
    }

    /// <summary>
    /// Validates and adds phone number candidates.
    /// </summary>
    private static void AddValidPhoneNumbers(
        ContactInformation result,
        IEnumerable<string> candidates)
    {
        foreach (var candidate in candidates)
        {
            var digitCount = candidate.Count(char.IsDigit);

            if (digitCount >= 7 && digitCount <= 15)
            {
                AddUnique(
                    result.PhoneNumbers,
                    new[] { CleanText(candidate) });
            }
        }
    }

    /// <summary>
    /// Normalises whitespace in extracted text.
    /// </summary>
    private static string CleanText(string value)
    {
        return Regex.Replace(
            HtmlEntity.DeEntitize(value ?? string.Empty),
            @"\s+",
            " ").Trim();
    }

    /// <summary>
    /// Adds values only when they are not already present.
    /// </summary>
    private static void AddUnique(
        List<string> destination,
        IEnumerable<string> values)
    {
        foreach (var value in values)
        {
            if (!string.IsNullOrWhiteSpace(value) &&
                !destination.Contains(
                    value,
                    StringComparer.OrdinalIgnoreCase))
            {
                destination.Add(value);
            }
        }
    }
}

Why separate classes?

A Contact page and an About page have different information structures. Keeping their extraction logic separate makes the system easier to test, maintain and extend.

Field	Example

We can extract these using HtmlAgilityPack. No AI or paid APIs are needed.
4. One issue to keep in mind
Your current WebsiteContactCollectionService calculates SHA256 from raw HTML. That means even an unrelated change, such as a tracking script or rotating banner, can change the hash.

For reliable historical change detection, we should hash normalized extracted information instead. We'll address this as part of the collection pipeline rather than changing your working contact extractor now.
